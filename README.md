# 深港 IX 测评：线路原理、云厂前置与 Mkcloud 深港 IX 套餐选购

在跨境专线里，"深港 IX"这四个字在过去一年里被频繁提起。深圳前海的 CNIX（前海互联网交换中心）原本是云厂之间对等互联的内部设施，后来被一些服务商包装成 VPS 产品，号称深圳到香港端内延迟 1~2ms、价格却只有传统 IEPL/IPLC 的一半。对于做跨境电商、素材上传或后台访问的人来说，这听起来像是"少花钱、还更快"的组合。但深港 IX 并不是随便一台本地宽带就能连的入口，它对前置网络、带宽稳定性和使用场景都有硬性要求。如果你正在搜索"深港 IX 测评"，大概率是卡在了"它到底是什么、能不能直接用、套餐怎么选"这三个问题上。下面结合 Mkcloud 这家专注跨境专线的服务商，把能查证的官方资料和已发布的测评数据整理成一篇选购参考。

## 深港 IX 是什么？和传统 IEPL/IPLC 差在哪

IX 全称是 Internet Exchange Point，中文叫互联网交换中心。深港方向的 IX，主要指深圳前海 CNIX——多家云厂和运营商在这里做对等互联，把原本要走公网绕行的流量，直接在交换中心内部完成对接。Mkcloud 知识库对 IX 的描述是："IX/IXP 是不同网络连接并交换互联网流量的基础设施，网络可通过对等互联缩短部分流量的路径，但加入交换中心不等于与所有成员直接互通"。

这条路线的两个关键特征决定了它的价格和用法：

入口是云厂内网，不是公网。深港 IX 的"入口 IP"是云厂内网地址，没有公网路由。你家里宽带、4G、普通 IDC 主机都连不进去，必须用阿里云、腾讯云、百度云、火山云或华为云华南的机器作为前置。这和 IEPL/IPLC 那种"绑定一个省份直接拨号就能用"的模式不一样。

延迟低但路径短。Mkcloud 资料显示，深港端内参考延迟 1~2ms。这是深圳到香港交换中心的实测数字，不等于你全程 RTT。本地到前置云机、前置到入口、香港到目标网站这几段还会再加时间。但即便如此，整链路延迟通常仍显著低于走公网绕道的传统方案。

价格相对友好。Mkcloud 官方资料给出的起步价是 158 元/月起（共享入门），对应深港 IX 共享流量款；广港 IEPL 共享入门 228 元/月，沪港 IPLC 共享入门 288 元/月。对比之下，IX 路径确实便宜一截——这也是大家愿意研究深港 IX 的核心原因。

不过这套便宜不是白来的。深港 IX 的所有责任都前置到了用户侧：DDoS 防护你得自己解决，公网入口的扫描风险依然存在，出了问题追责链路会追到云厂实名账号。Mkcloud 在知识库里直接写明："接入限制不等于完全不可探测或免疫 DDoS，前置和 VPS 仍需加固"。

## 接入条件：为什么必须有云厂前置

深港 IX 不是"买一台就能跑"的 VPS，它要求你的前置机器必须落在支持范围内。Mkcloud 知识库明确列出的深圳入口支持范围：

| 云厂 | 支持范围 |
| --- | --- |
| 阿里云 | 国内全网 |
| 腾讯云 | 国内全网 |
| 百度云 | 国内全网 |
| 火山云 | 国内全网 |
| 华为云 | 华南 |

不在这个范围内的云厂、其它地区的华为云、或普通 BGP 主机，不能作为深港 IX 的前置。这一点和"绑定一个省份"的直连专线有本质区别——直连款你可以选电信、移动、联通，只要省份对就行；IX 款你必须在指定云厂里选一台机器。

实际选前置机器时，社区里被讨论最多的是阿里云和腾讯云的轻量实例。猫猫博客的实测指出，这些标称 200M 带宽的轻量实例带宽并不具备强保证，已经出现过被限速到 20M 甚至 1M 的案例。如果你对前置稳定性要求高，火山引擎的按量 ECS 是一个常被提到的选项，但它的流量成本大约 0.8 元/GB，长期使用并不便宜。

简单说，前置机的费用要一起算。158 元/月只是 Mkcloud 深港 IX 自己的起步价，前置云机的机器费 + 流量包加起来，通常还要再加一截。这笔隐性成本是搜索"深港 IX 测评"时最容易被忽略的地方。

几个值得注意的细节：

- 每台 VPS 都分配 1 个独立入口 IP 和 1 个独立出口 IP（单端双 IP），共享套餐和独享套餐都按这个标准给，不是共用 IP 池。
- 计量型套餐按上行、下行双向统计流量，超量后会暂停，不会自动按高价继续跑。流量用完之后可以自助购买流量重置，或者提交工单补差价升级。
- 共享峰值不保证持续跑满。这条适用于所有共享套餐，短时上传体验好，长时间大文件传输不一定能稳定打到峰值。
- 下单后约 1 分钟自动开通，官方口径如此，实际受支付和库存影响。
- 默认无 SLA 保证。Mkcloud 在知识库和公告里都明确写过"标准产品默认无 SLA"，如需 SLA 保障需要付费定制。
- 退款政策：仅质量问题支持退款，需要在工单中提交测试截图和具体问题，开通后不支持更换地域。

香港 BGP 出口端的资源列表官方也有说明：接入 PCCWG、RETN、NTT、Cogent、Lumen、Telstra、HE、Voxility 等运营商；多交换中心含 Equinix IX、HKIX；私有 PNI 专线包括 Google、Cloudflare、Valve、SGGS。但官方也提示："这些资料不证明所有目标都走私有直连，也不是第三方性能认证"。

关于延迟，作者在 21:00 和 23:00 两个时间段做了入口延迟测试（catcat 博客里有 Grafana 图表），并提醒"短时间测试没放完整 Grafana，后面会补上"。也就是说，目前公开数据能告诉你"1~2ms 是端内参考"，但独立用户从本地拨号到目标站点的完整 RTT 数据，公开实测还比较零散。如果你的业务对延迟稳定性敏感，建议自己用 mtr / besttrace 跑一次回程。

## 适用场景：谁应该买深港 IX

深港 IX 不是万能方案。结合 Mkcloud 知识库列出的应用场景与社区里的讨论，适合它的任务主要有几类：

跨境电商后台操作。Shopee、TikTok Shop、亚马逊等平台的后台访问和文件上传，是深港 IX 最被推荐的使用场景。香港 BGP 出口对大部分国际路由友好，云厂前置又能给到一个相对干净的网络环境。

素材与文件上传。短视频素材、店铺图片、合规文件等的批量上传，对峰值带宽有要求但对延迟不极端敏感。共享 200Mbps~500Mbps 的峰值在大多数情况下够用。

海外 SaaS 访问。Notion、Linear、Figma 等需要稳定国际出口的服务，通过 IX 路径走通常比公网更稳。

不适合它的场景也很明确：

- 公网站点、API 回调、游戏服务端——Mkcloud 知识库写得很清楚："出口不支持外部连入，不用于公开网站、回调或游戏服务端"。
- 没有云前置的个人用户——买回去连不上，等于浪费。
- 对 DDoS 防护有硬性要求的业务——IX 不自带公网清洗能力，需要额外方案。

如果你已经在云厂里租了一台 ECS 并且有稳定任务需要跨境出口，深港 IX 是一个值得对比的选项。如果你只是单纯想买一台"能上香港的 VPS"，走广港 IEPL 或沪港 IPLC 这类绑定省份的直连方案会更省事。

## 选购时几个容易被忽略的点

第一，分清"共享"和"独享"。Mkcloud 的共享与独享区分的是带宽模式，不是 IP 数量。共享套餐的峰值不保证持续跑满，适合间歇性任务；独享套餐按持续速率计费，适合长时间大流量传输。两者每台都有 1 个独立入口 IP + 1 个独立出口 IP，不要被"共享 IP"的说法误导。

第二，流量是双向统计的。Mkcloud 知识库明确："计量型套餐按上行、下行双向统计流量，达到额度后暂停"。如果你以为只算出口，那会在月中被打断。

第三，深圳入口与上海入口是两套支持范围。深港 IX 是深圳入口，支持阿里云、腾讯云、百度云国内全网，以及火山云、华为云华南；上海入口对应的是沪港/沪日/沪美 IX，覆盖范围不同（沪港/沪日/沪美 IX 还支持 UCloud 华东）。如果你换业务方向，记得重新核对前置支持范围。

第四，注意历史优惠码不要套用。MK-8.8、MK-7.8、MK-NEW、ALIYUN-NEW、CLOUD-2T-NEW 等优惠码都已经在对应活动回顾里标注"活动已结束"。下单时不要照搬网上的旧优惠码。

第五，售后服务走工单。Mkcloud 的产品支持主要通过 Telegram 群和工单系统，没有电话客服。升降级也需要提交工单处理——降级至更低价格套餐时差价不退。

## 深港 IX 选购的判断清单

在点下单按钮之前，可以快速过一遍这五条：

1. 你已经有云厂前置了吗？没有的话，深港 IX 不适合你。
2. 你的任务是跨境后台、上传、SaaS 访问？如果是，深港 IX 合适；如果是开网站或游戏服务端，不合适。
3. 你能接受默认无 SLA 吗？Mkcloud 标准产品没有 SLA 承诺，重要业务需要付费定制。
4. 你的流量是突发还是持续？突发选共享峰值即可，持续大流量考虑独享或更高带宽套餐。
5. 你的预算是否包含云前置？158 元/月只是 IX 套餐价，前置云机通常还要再加。

如果这五条都能回答，深港 IX 是一个相当合理的方案；如果第 1、3 条回答不上，建议先回到广港 IEPL 或沪港 IPLC 这类绑定省份的直连方案，那才是"即开即用"的传统专线形态。
